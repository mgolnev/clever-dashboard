# Вход в CLEVER Dashboard

Используется один общий аккаунт. Регистрации и разделения прав нет.

## Локальный запуск

Логин и пароль находятся в `.env.local` в корне проекта (файл исключён из Git).
Скрипт `./scripts/restart-dev.sh backend` загружает этот файл перед запуском.
Открыть http://localhost:3000 и ввести значения AUTH_USERNAME / AUTH_PASSWORD.
Кнопка «Выйти» находится в шапке дашборда.

## Настройка сервера

В Amvera откройте проект **clever-dashboard** → вкладка **Переменные** →
**Добавить переменные или секрет**. Добавьте перечисленные значения без кавычек;
для пароля выберите тип **секрет**. Для Docker Compose используйте `.env`.

Задать до релиза:

- `AUTH_USERNAME`: логин, по умолчанию `admin`.
- `AUTH_PASSWORD`: длинный случайный пароль (не менее 12 байт), обязательный.
- `AUTH_COOKIE_SECURE=true`: для публичного HTTPS, даже при TLS на reverse proxy.
  `false` допустим для локального HTTP.

Без корректного пароля backend не стартует. Для прямого `go run` переменные
нужно экспортировать в окружение; Go автоматически `.env` не читает.
Не использовать префикс VITE_ для секретов.

Сессия сохраняется при обновлении страницы и действует 12 часов. Выход отзывает
её на сервере. При перезапуске backend все пользователи входят заново.
Для смены пароля изменить AUTH_PASSWORD и перезапустить backend.

Сейчас поддержан один экземпляр backend. За reverse proxy ограничение входа
может быть общим: 10 запросов в минуту на IP соединения.
